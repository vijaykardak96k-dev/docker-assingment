# Docker Full Stack Application

TuteDude DevOps Docker Assignment.

## Architecture
- Frontend: Node.js and Express
- Backend: Python and Flask
- Containerization: Docker
- Orchestration: Docker Compose

## Run

docker compose up -d --build

## Access

http://localhost:3000

## Services
- Express frontend: Port 3000
- Flask backend: Port 5000 (internal Docker network)

## Docker Hub
- vijaykardak/docker-assignment-frontend:v1
- vijaykardak/docker-assignment-backend:v1
